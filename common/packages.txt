# packages.txt — system packages shared by every platform.
#
# One package per line; blank lines and lines starting with `#` are
# ignored. Installed by `just sync` (_apt) via the platform's package
# manager, skipping anything already installed.
#
# This holds ONLY the irreducible system layer — what must exist before
# mise can run, or what mise can't manage:
#   - zsh: the login shell (needs a stable path for /etc/shells)
#   - git/curl/ca-certificates: bootstrap — clone this repo, install mise
#   - stow: the config linker (perl script, no binary release)
#   - just: runs this justfile
#   - unzip: some tool installers still expect it
#
# Everything else is managed by mise — see mise/.config/mise/config.toml.
# mise pins latest, verifies checksums/attestations, and works the same
# on every platform. The zsh plugins (autosuggestions, syntax-highlighting)
# are managed by sheldon (binary via mise, config via stow) — not packages.
#
# These names are identical in apt, dnf, and brew — keep it that way;
# anything platform-specific or differently-named goes in
# <platform>/packages.txt (e.g. build-essential lives in wsl/ + desktop/).
